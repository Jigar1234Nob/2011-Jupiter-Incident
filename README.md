# 2011 Jupiter Incident

A 2D analog-horror, Doom-style game. Choose a crew member, live their backstory, then survive (or don't) aboard the ISV Mercator.

Real 2011 events (Juno launch, the October solar storm hitting Jupiter, the lost moon S/2011 J 2) frame a fictional crew.

Play: open the GitHub Pages site for this repo. Controls: WASD / arrows / mouse, Space to interact, Esc to pause. Touch: left stick to move, drag right side to turn, ACT button.
