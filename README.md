# The 2011 Jupiter Incident

A 2D analog-horror, Doom-style game based on the "2011 Jupiter Incident" internet creepypasta/meme: a fictional, classified NASA mission (Odyssey 9, JX-11) whose black box was "recovered" in 2026.

Choose a crew member, live their backstory, then find escape-pod parts while the Keis hunt you. Escape, die, or go missing.

This is fiction. No real mission was lost in 2011. Crew names are invented.

Controls: WASD / arrows / mouse, Space to interact, Esc to pause. Touch: left stick to move, drag right side to turn, ACT button.

Editing the crew: names, backstories and the intro text live in `characters.js`. Change `VILLAIN` there if you rename the traitor.
